# FIREZONE 烽区行动

网页端吃鸡（第一人称 / 第三人称），静态资源一次加载到手机，服务器只做登录、房间、战斗校验和后台管理。

## 启动

1. 安装 [Node.js](https://nodejs.org)（已安装可跳过）
2. 双击 `start.bat`，或在本目录执行：

```bash
npm install
npm start
```

3. 浏览器打开 http://localhost:8080  
   手机请用电脑局域网 IP，例如 `http://192.168.1.8:8080`，建议横屏。

## 功能

- 最多 100 人房间，人机补位，好友组队（单人/双人/四人）
- 跳伞、滑翔、拾取、射击、载具、毒圈、空投
- 建筑可进入：走门洞进屋，屋内刷装备，墙面可挡子弹
- 武器/医疗掉落有光柱标识；大地图（M）显示装备/载具位置
- 第一/第三人称（默认第三人称，按 V 或屏幕「人称」切换）
- 商店、服装、风景时段
- 后台：用户/房间/武器/载具/地图/商店/服装/风景
- 管理员 GM：透视、自瞄、锁血、无限子弹、呼叫轰炸区（F1–F5 或局内按钮）

## 操作

**电脑** WASD 移动 · 鼠标瞄准 · 左键射击 · 空格跳伞/跳跃 · C 蹲 · R 换弹 · E 拾取/上车 · V 人称 · M 地图 · Tab 战绩 · Enter 聊天 · Shift 冲刺

**手机** 左摇杆移动 · 右侧滑动瞄准 · 射击/跳/蹲/换弹/交互

## 架构

- 客户端：Three.js 低模岛屿 + 本地预测，资源经 Service Worker 缓存（网络优先，更新即时生效）
- 服务端：Socket.io 20Hz 快照，命中/伤害/毒圈/空投由服务器校验；移动按速率上限"截断跟随"（防瞬移同时绝不回弹死循环）
- 地形：`shared/terrain.js` 客户端与服务端共用同一份代码生成岛屿/城镇/树木，保证位置判定一致
- 数据：`data/db.json`（武器、载具、地图、商店、账号均可在后台改）
