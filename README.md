# FIREZONE 烽区行动

纯网页 3D 大逃杀（吃鸡）游戏 —— 无需安装客户端，打开浏览器就能空降开打。支持电脑键鼠与手机触屏，同一 WiFi 局域网即可与好友组队开黑。

## 玩法特性

- **空降开局**：运输机航线跳伞 + 滑翔操控，落点自己选（房顶也能站）
- **百人对局**：房间人数上限可配（默认 60），不足由机器人补位，AI 会捡枪、开车、攻楼
- **组队开黑**：单人 / 双人 / 四人小队，按进房顺序自动分队，同队免伤
- **房间分享链接**：建房自动生成邀请链接（含局域网地址），好友打开链接登录后自动进房
- **开局规则**：不自动开局；全员准备后仅房主可点击「立即开始」
- **武器系统**：多种枪械（伤害/射速/弹匣/散布可后台调）、开镜瞄准、换弹、护甲减伤
- **载具**：吉普/越野车，可驾驶、可撞人、有墙碰撞检测
- **缩圈毒圈**：多阶段安全区 + 血条侵蚀 + 屏幕红雾提示
- **空投补给**：飞机定期空投高级物资，落地有检测可拾取
- **可进入建筑**：门洞进出，屋内刷装备，墙体挡子弹
- **四种时段**：黎明 / 白天 / 黄昏 / 夜晚（夜战有夜视效果）
- **外观商店**：多部件套装（上衣/手臂/裤腿/背包分色），3D 旋转试穿，金币购买
- **成长系统**：击杀/吃鸡奖励金币，排行榜，自定义昵称

## 快速开始

1. 安装 [Node.js](https://nodejs.org)（v18+）
2. 启动服务：

```bash
npm install
npm start          # 或双击 start.bat（Windows）
```

3. 本机打开 <http://localhost:8080>
4. **手机 / 好友联机**：连接同一 WiFi，访问启动日志打印的局域网地址（如 `http://192.168.3.31:8080`），建议横屏

> 若局域网访问不通，请检查 Windows 防火墙是否放行了 Node.js 与 8080 端口。

## 后台管理

- **概览**：注册用户 / 在线 / 房间 / 战斗中场次 / 运行时长 / 内存，一键发全服公告
- **用户**：搜索、封禁（禁止封禁自己与最后一个管理员）、金币、角色、重置密码、改名、删除、送全皮肤
- **房间**：成员名单、单独踢人、解散房间（战斗中强制结束并结算）
- **配置**：武器 / 载具 / 地图 / 商店（套装四色拾取器）在线 CRUD，新开局生效
- **设置**：每局总人数、机器人命中系数、击杀/吃鸡奖励

**管理员 GM 工具**（对局内）：F1 透视 · F2 自瞄 · F3 锁血 · F4 无限子弹 · F5 呼叫轰炸区（局内左上角也有按钮面板）

## 架构

```
public/            前端（无构建，直接 ESM）
  index.html         游戏页
  admin.html         后台管理页
  js/game.js         Three.js 战斗客户端（渲染/预测/交互）
  js/main.js         登录、大厅、房间、商店、分享链接
  sw.js              Service Worker（网络优先 + 离线回退，版本号强制更新）
server/
  index.js           Express + Socket.io 入口
  api.js             REST：登录/商店/排行/后台管理
  game.js            战斗权威模拟：房间、20Hz 快照、命中/毒圈/空投/载具/机器人
  db.js              JSON 文件数据库（带默认数据与增量迁移）
shared/terrain.js   客户端/服务端共用地形生成（保证位置判定一致）
test/               E2E 测试（见下）
```

- **同步模型**：客户端本地预测 + 服务端 20Hz 快照；移动校验采用「截断跟随」——超速按上限截断、永不回弹，兼顾防作弊与弱网体验
- **权威在服务端**：命中、伤害、毒圈、空投、载具碰撞均由服务器判定
- **认证**：JWT + bcrypt 密码哈希；Socket 连接与 REST 均校验 token

## 常见问题

- **手机打不开**：确认与电脑同一 WiFi；防火墙放行 Node.js；用启动日志打印的局域网 IP
- **更新后界面没变**：Ctrl+F5 强制刷新（Service Worker 会自动升级缓存）
- **忘记管理员密码**：删除 `data/db.json` 后重启会重建默认账号（会清空玩家数据，慎用）
